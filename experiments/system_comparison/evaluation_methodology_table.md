# Table 3: Evaluation Methodology Comparison

This table compares the research objectives, experimental baselines, evaluated metrics, workloads, and reproducibility status across the four examined systems.

| System | Evaluation Objective | Baseline | Metrics | Workload or Dataset | Reproducibility Status | Source |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **RetailOps** | Systems engineering: Dissect process lifecycle latency, MCP overhead, service replacement churn, extensibility, and fault recovery | Paired in-process Python baseline executing identical algorithms in-memory | LOC churn, process initialization time (ms), warm call latency (ms), failure detection rate, downstream protection rate, process cleanup rate | Deterministic local retail datasets (catalog, historical sales, inventory, pricing, suppliers) | Fully reproducible local repository, automated test battery, raw JSONL telemetry | RetailOps Repository & Task 04–08 Artifacts |
| **Flowr** | Enterprise operational validation: Evaluate automated supply chain exception management and workflow coordination | Not established from reviewed source | Proactive exception management, operational alignment between supply and demand, managerial coordination overhead | Live supermarket enterprise supply chain workflows in commercial retail collaboration | Academic preprint published (arXiv:2604.05987); full code and enterprise data not established | Bandara et al. (2026), arXiv:2604.05987 |
| **WorkflowLLM** | Machine learning / NLP: Evaluate LLM capability to generate, execute, and adapt multi-step tool-use workflows | Foundation LLMs without workflow fine-tuning (Llama-3.1, GPT-4) | Workflow generation accuracy, tool selection precision/recall, argument parsing F1, out-of-distribution generalization on T-Eval | WorkflowBench (106,763 synthesis/execution samples, 1,503 APIs across 83 applications) | Open-source GitHub repository and dataset publicly available | Fan et al. (ICLR 2025), arXiv:2411.02052 |
| **Agentic Inventory Replenishment** | Retail operations: Evaluate reduction of inventory holding costs and stockouts compared to traditional heuristics | Traditional inventory heuristics (Economic Order Quantity [EOQ], Reorder Point [ROP]) | Stockout frequency, inventory holding costs, product mix turnover, order fill rate | Multi-SKU middle-scale retail mart operational data and simulation environment | Academic preprint published (arXiv:2511.23366); standalone code repository not established | Syed et al. (2025), arXiv:2511.23366 |
